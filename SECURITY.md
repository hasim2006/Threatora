# Security Policy 🛡️

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is paramount to Threatora. If you discover a vulnerability or potential security issue in the framework or detection pipeline:

1. **Do not disclose the issue publicly** in GitHub issues, forums, or social media.
2. Please send a detailed report via email to **`juug25btech29109@jainuniversity.ac.in`**.
3. Include as much information as possible:
   - Type of vulnerability (e.g., adversarial evasion, code execution, dependency vulnerability)
   - Step-by-step reproduction instructions or proof-of-concept
   - Impact assessment
   - Suggested mitigations (if available)

We will acknowledge receipt within 48 hours and work with you to remediate and publish an advisory once patched.
